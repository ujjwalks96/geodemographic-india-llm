> 📥 [data.gov.in — NFHS-5 India Districts Factsheet Data (Provisional)](https://www.data.gov.in/catalog/national-family-health-survey-5-nfhs-5-india-districts-factsheet-data-provisional)

> 🌐 [IIPS NFHS-5 District Factsheets Portal](http://rchiips.org/nfhs/districtfactsheet_NFHS-5.shtml)

After downloading, save the file as:
```
data/NFHS_5_India_Districts_Factsheet_Data.xls
```
Then run Cell 3 of the notebook which will prompt you to upload this file to Colab.
